# Patches JSON

Envie aqui arquivos `.json` de patches compatíveis com o formato CheatRunner para avaliação.

**Nome sugerido:** `PPSA12345_01.000.000_60fps.json`.

No Pull Request, informe jogo, versão exata, autor, descrição das alterações e resultado dos testes. Preserve os campos de identificação e os valores originais ON/OFF.

> Enviar o JSON não modifica o ELF nem o `patches.db` já publicados. A inclusão exige análise e uma nova compilação.
