# Patches MC4

Envie aqui arquivos `.mc4` (formato CheatRunner/etaHEN) para avaliação.

**Nome sugerido:** `PPSA12345_01.000.000_60fps.mc4`.

No Pull Request, informe jogo, versão exata, autor, descrição das alterações e resultado dos testes. Preserve **todos os offsets e valores ON/OFF** do arquivo original.

> Estes arquivos não são carregados automaticamente pelo ELF distribuído. A inclusão exige análise e uma nova compilação do FPS Global.
