# Patches XML

Envie aqui arquivos `.xml` de patches PS5 para avaliação.

**Nome sugerido:** `PPSA12345_01.000.000_60fps.xml`.

No Pull Request, informe jogo, versão exata, autor, descrição das alterações e resultado dos testes. Indique qual formato XML foi usado (por exemplo, Trainer/CheatRunner ou patch XML) para facilitar a validação.

> Os arquivos enviados não são instalados ou ativados automaticamente pelo ELF da Beta v1.0. A inclusão exige análise e uma nova compilação.
